# Task 5: Host a Static Website with GitHub Pages

## Objective
Deploy a static website using GitHub Pages.

## Technologies Used
- HTML5
- CSS3
- Git
- GitHub
- GitHub Pages

## Project Description
Created a personal DevOps portfolio website using HTML and CSS.
The website contains About Me, Technical Skills, Projects
and Contact sections.

## Deployment
1. Created an index.html file.
2. Initialized a Git repository.
3. Pushed the project to GitHub.
4. Enabled GitHub Pages from repository settings.
5. Selected main branch and root folder.
6. Verified the live website.
